# Medios científicos y derechos

Activar al buscar/adquirir medios o cambiar referencias curadas. Reutilizar `docs/FUENTES_ANATOMICAS.md` y la skill anatomy-integrity; no repetir solicitudes 403.

- Distinguir fuente bibliográfica, archivo y página original. Registrar autor, especie/región/estructuras, licencia/versionado, atribución, fecha de comprobación y revisión científica. La coincidencia visual no valida identidad.
- Priorizar fuentes primarias veterinarias y NAV para términos. Consultar repositorios académicos por registro concreto: un catálogo general no habilita descarga ni redistribución.
- Imágenes internas requieren derechos claros y archivo inspeccionado; comprobar tamaño, tipo, checksum y miniatura. No descargar recursos restringidos ni reproducir contenidos comerciales/institucionales sin permiso.
- Ante licencia desconocida o limitada, conservar referencia externa sin miniatura ni hotlink. Validar HTTPS/dominio/ausencia de credenciales, usar enlaces seguros y nunca un proxy abierto.
- Separar fotos de disección, TC, RM, ilustraciones y modelos. No usar Google como catálogo; una búsqueda externa opcional no se importa ni valida automáticamente.

Verificar: IDs/fuentes existentes, URL segura, permiso compatible para imágenes internas, correspondencia de especie/estructura, atribución visible y estado approved/pending/rejected honesto. Si faltan medios, entregar enlaces académicos y pendientes; no inventar fotos o geometría.
